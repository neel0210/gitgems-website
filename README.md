# GitGems.ai Website

Official web application and live open-source trending radar for **[GitGems.ai](https://gitgems.ai)**.

- 💎 **Live Trending Radar**: Real-time velocity and star counts verified from GitHub.
- 🎬 **Social Spotlight**: Embedded reels and video breakdowns across YouTube, Instagram, and Facebook.
- ⚡ **AI & Tech News Radar**: Daily curated stories scouted from Hacker News, TechCrunch, and Ars Technica.
- ✨ **Feature Submissions**: Direct repository submission form for creators and maintainers.
